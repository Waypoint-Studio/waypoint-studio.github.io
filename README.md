# waypoint-studio.github.io

Sitio web de Waypoint Studio, publicado con GitHub Pages en https://waypoint-studio.github.io.

Página estática sin build: `index.html` con estilos embebidos y `favicon.svg`. Para verla en local basta con abrir `index.html` en el navegador.

## Demos

- `demos/reparaciones/`: demo de Reparo, software para locales de reparación de celulares. Es el resultado compilado; el código está en `apps/reparaciones/` (ver su README).
